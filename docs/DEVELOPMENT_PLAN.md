# Development Plan

## Phase 1 — Foundation and governance

- confirm workspace state
- create project specification and architecture
- define acceptance criteria
- initialize project tracker and evidence structure
- create Git repository and baseline repo configuration
- prepare initial project structure

## Phase 2 — Data and validation

- generate synthetic admission dataset with fixed seed
- define schema and data dictionary
- implement validation and profiling logic
- capture dataset evidence and profiling report

## Phase 3 — Analytics

- implement funnel metrics and cohort logic
- compare programmes and regions
- run attribution analysis with descriptive language
- generate analytical reports

## Phase 4 — ML and explainability

- preprocess data
- train baseline logistic regression model
- train advanced ensemble model
- evaluate metrics and calibration
- generate explainability and error analysis

## Phase 5 — Forecasting and simulation

- build temporal forecasting pipeline
- evaluate H1, H2, H4, H6 performance
- implement deterministic scenario simulation
- record results and assumptions

## Phase 6 — Backend and security

- implement FastAPI backend
- add auth and OAuth-ready flow
- enforce authorization and audit logging
- validate error handling and protected routes

## Phase 7 — Frontend

- create dashboard and analytics pages
- implement light/dark theme
- ensure responsive and professional UI behavior
- create error, loading, and empty states

## Phase 8 — Quality and evidence

- run unit, integration, failure, security, and UI tests
- collect screenshots, metrics, and artifact evidence
- update tracker and final reports
- verify Git state and completion criteria

## Milestone rule

After every milestone: implement, test, verify, capture evidence, update tracker, commit, and continue.
