# Reference Blackbook Specification

This specification records the visual and structural rules inferred from the sample blackbook PDF in the repository root.

## 1. Page geometry
- Page size: A4 portrait (approximately 210 x 297 mm)
- Orientation: portrait throughout the document
- Margins: consistent page margins with generous whitespace around text blocks
- Layout: single-column body with centered cover/title pages and mostly left-aligned chapter content
- Section spacing: clear vertical breaks between front matter, chapters, and appendices 

## 2. Typography
- Primary text: serif font family, closely resembling Times New Roman or a similar academic serif
- Headings: bold or semibold serif headings, arranged in cascading sizes
- Body text: academic paragraph style with normal line spacing and modest paragraph spacing
- Emphasis: bold for key terms; italics used sparingly for terms and project names when needed
- Capitalization: standard academic title case for chapter and section headings

## 3. Heading hierarchy
- Cover page title: largest text, centered, all caps or title case
- Certificate and approval pages: centered headings with standard report formatting
- Chapter titles: uppercase or title-case headings, typically separated by generous vertical whitespace
- Section headings: numeric system such as 1.1, 1.2, 2.1, etc.
- Subsections: nested numbering with a consistent academic pattern

## 4. Paragraph rules
- Body text: justified or left-aligned academic paragraphs
- Paragraph spacing: moderate, consistent spacing between paragraphs
- First-line indentation: not used consistently for all body text; depends on the section style
- Lists: numbered lists or bullet points with formal academic formatting

## 5. Table rules
- Tables are simple, restrained, and border-based
- Headings are bold and centered or left aligned
- Rows are readable with minimal decorative styling
- Use narrow tables only when necessary; avoid overuse of wide or complex tables

## 6. Figure rules
- Figures and screenshots, when included, are placed after a relevant section heading
- Captions are concise and academic
- Images are aligned centered or left with a clean borderless presentation

## 7. Page numbering and headers
- No elaborate running headers are visible in the sample
- Page numbers are simple and usually centered or near the lower page area
- Front matter is treated as a report sequence rather than a modern dashboard style

## 8. Front matter structure
1. Cover page
2. Certificate
3. Approval/proposal proforma
4. Abstract
5. Acknowledgement
6. Declaration
7. Table of contents

## 9. Chapter structure
- Chapter 1: Introduction
- Chapter 2: System Analysis
- Chapter 3: System Design
- Chapter 4: Implementation and Testing
- Chapter 5: Results and Discussions
- Chapter 6: Conclusion and Future Work
- Chapter 7: References

## 10. Back matter and references
- References section is a formal academic list of sources
- Use explicit source names and URLs when available
- Avoid decorative metadata or modern UI-style reference cards

## 11. Visual tone
- monochrome or minimal grayscale document
- no bright colors, gradients, dashboards, or card-based UI styling
- strictly academic and institutional in tone

## 12. Core interpretation for this project
The final AdmitFlow document should preserve the same academic blackbook structure and conservative visual language while replacing the sample content with project-specific admissions analytics material, actual repository evidence, and explicit placeholders only where the repository does not provide a verified value.
