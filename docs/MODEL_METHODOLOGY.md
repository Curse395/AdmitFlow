# Model Methodology

## Objective and data

The classifiers estimate the synthetic `enrolled` flag. The current dataset contains 4,200 synthetic applicant rows; 351 are enrolled (8.36%). Results are useful for demonstrating a pipeline only. They are not validated for admissions decisions or real-world prediction.

## Features and preprocessing

Features are `programme`, `selectivity`, `region`, `campaign_source`, `academic_score`, `gpa`, `engagement_score`, `interest_score`, `outreach_count`, `campaign_clicks`, `distance_km`, and `cycle_year`. The exclusive `stage`, applicant ID, outcome flags other than `enrolled`, `campaign_code`, and application date are excluded to avoid direct outcome leakage or identifier noise.

Numerical inputs are median-imputed. Categorical inputs are most-frequent-imputed and one-hot encoded with unknown categories ignored. A stratified 75/25 random split uses `random_state=42`. The baseline is balanced logistic regression; the advanced estimator is a 200-tree random forest with `min_samples_leaf=2`.

## Observed holdout results

These values were generated by `scripts/capture_evidence.py` and are stored in `evidence/models/model_report.json`.

| Model | Log loss | ROC-AUC | PR-AUC | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.6611 | 0.5573 | 0.0964 | 0.6143 | 0.1028 | 0.4659 | 0.1684 |
| Random Forest | 0.2975 | 0.5195 | 0.1037 | 0.9162 | 0.0000 | 0.0000 | 0.0000 |

The holdout contains 88 enrolled and 962 non-enrolled records. At the default 0.5 classification threshold, the random forest predicts every holdout record as non-enrolled. Its accuracy therefore reflects the class imbalance, not useful positive-case detection. The logistic model finds more positives but has low precision. ROC-AUC is near chance for both; neither is suitable for decision support.

## Explainability and error analysis

The report includes the top ten transformed feature signals for each model. Logistic regression reports absolute coefficient magnitude; the random forest reports impurity-based feature importance. These values describe model associations, are sensitive to correlated features, and are not causal effects. Confusion matrices are included in the report for threshold-specific error analysis.

## Limitations and next work

- The generated target has weak predictable signal in the selected feature set.
- The class imbalance makes accuracy misleading; PR-AUC and positive-class metrics deserve priority.
- A single random holdout does not establish stability. Use repeated or temporal validation before making comparisons.
- Threshold selection, calibration, subgroup error checks, confidence intervals, and independent real data are not implemented.
- Do not use these models to rank, admit, reject, or otherwise make decisions about real applicants.
